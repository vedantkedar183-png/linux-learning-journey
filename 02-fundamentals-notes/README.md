# 02 — Linux Fundamentals Notes

These are the **concepts** — the "why" and "what", not the "how". Read these slowly. Once the ideas
are clear, the commands feel obvious instead of memorised.

| Note | Question it answers |
|---|---|
| `01-what-is-linux.md` | What actually *is* Linux? |
| `02-kernel-shell-and-desktop.md` | What are the kernel, shell, terminal, and DE? |
| `03-filesystem-hierarchy.md` | Why is everything under `/`? What lives where? |
| `04-users-groups-and-ownership.md` | Why does every file have an owner? |
| `05-permissions-explained.md` | What does `-rwxr-x---` really mean? |
| `06-processes-and-jobs.md` | What is a process, a PID, a job, a service? |
| `07-package-management.md` | Why install software differently? |
| `08-boot-and-services.md` | What happens between power-on and login? |
| `09-glossary.md` | What does that word mean? |

**How to read:** one note per session. After each one, do the "Prove you understood" question at the
bottom, out loud. If you can teach it simply, you own it.
